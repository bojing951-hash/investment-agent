## 1. 历史相似结构检索工具(`analog`)规格

### 1.1 状态向量: 维度×指标×变换

月度网格为宏观时钟(宏观状态的最细共同频率)。全部特征在"锚点月"的**月末快照**上取值。

| 维度 | 特征(现役数据) | 变换 | 扩展后增补 |
|---|---|---|---|
| 增长 growth | UNEMPLOYMENT 水平; NFP 3 个月均值环比变化; INDPRO 同比(12 个月 pct); RSAFS 同比 | 水平值 + 同比/变化量 | GDP 同比(季→季末月对齐); ICSA 月末 4 周均值(周→月聚合) |
| 通胀 inflation | CORE_CPI 同比; CPI 同比; BEI_10Y 月末水平(市场口径日频) | 同比 + 水平 | (BEI 已日频, 无需) |
| 利率 rates | FED_FUNDS 水平; UST_10Y 水平; TIPS_10Y 水平; CURVE_2S10S 水平 | 水平值 + 12 个月变化 Δ12m(利率类 pp) | 同口径仅历史变长 |
| 信用 credit | HY_OAS 月末水平; HY_OAS−IG_OAS 月末差(风险分层) | 水平 + Δ12m | 同 |
| 波动 volatility | VIX 月末水平; SPX 21 日已实现波动率(收盘对数差标准差×√252, 月末窗) | 水平 | 同 |
| 估值 valuation | **现无数据 → 维度整体缺席, 如实标注** | — | 估值代理(口径落地后自动启用; 近似口径必须在维度贡献里标 "proxy/近似") |

**变换规则(方法论核心决策, 逐条理由)**:
- **水平值仅用于跨年代天然可比的量**(利率、利差、失业率、VIX、通胀同比): 这些量的水平有绝对语义(4% 利率在任何年代含义近似), 直接用。
- **价格/指数类水平一律不用**(SPX 600 vs 6000 无意义): 其信息经由"同比/Δ12m/z"进入, 或作为事后表现(§1.5)出现。
- **每个特征统一再变换为 z-score, 基准=该特征在候选锚点时点前的扩展历史(expanding window)**: z_t = (x_t − μ_{≤t}) / σ_{≤t}, μ/σ 只用 t≤锚点月末的观测。理由: (a) 跨年代可比性靠 z 而非原始量纲; (b) **用全样本均值做基准是泄漏**(用了未来分布), 扩展窗严格点时; (c) 不用分位数映射: 分位数在尾部塌缩(所有 >95 分位互相同"相似"), 丢失幅度信息, z 保留。
- **最小历史门槛**: 某特征在候选锚点时历史 <36 个月观测 → 该特征在该候选上弃用并计入 features_dropped; 有效维度 <4/6 → 该候选整体无效(refused candidate, 计数披露)。锚点自身不满足 → 工具整体拒答(kind=insufficient_history), 不降门槛硬算。
- **同比口径**: 月频序列取 observation_date ∈ (t−12, t] 的首末观测 pct; 不足 12 个月 → 该特征弃用(不缩短窗口冒充同比)。
- **周→月聚合(ICSA)**: 月末 4 周均值(取 observation_date ≤ 月末的最后 4 个周观测); 日→月聚合(UST/TIPS/OAS/VIX/BEI): 月内末值(与现有 align_to_month 期间末值规则同构, 复用 rhq.align_to_month)。
- **季→月(GDP, 扩展后)**: 季末月对齐, 值复制到该月(同比仍按 4 季)。

**权重**: 默认**六维等权, 维度内特征等权**(每特征 w = 1/6/该维特征数)。理由: 历史样本(候选数 ≤120)下任何数据驱动权重估计都是过拟合, 且权重学习本身引入泄漏风险; 等维等权=透明、确定性、零调参。CLI 提供 `--weights` 显式覆盖(仅限维度级, 六个非负数和为 1), 但默认等权且输出必须随行 weights 实值。

### 1.2 相似度度量

- 度量: **加权 z 距离**(欧氏距离在 z 空间的加权版): D(anchor, cand) = sqrt(Σ_i w_i · (z_i^anchor − z_i^cand)²), 求和仅over双方都有效的特征(权重按有效特征重新归一, 归一事实随行披露)。
- 报告双口径: 原始距离 D + **距离分位** = D 在全部有效候选距离分布中的百分位(分位越小越相似)。分位口径对用户更直观且对特征数变化稳健。
- 拒绝的替代方案(实现时不得私自更换): 分位数映射+欧氏距离(尾部塌缩); DTW(允许时间错位的相似会制造"滞后拼图"伪机制); 马氏距离(需估计协方差, 120 观测下不稳定且引入泄漏面)。

### 1.3 锚点、特征窗与检索库

- **锚点月 M0**: 默认=最新**完整月**(有 ≥80% 维度数据的最后一个月); CLI 可 `--anchor 2026-09` 回放历史锚点(研究自身历史, 合法)。
- **特征窗**: 12 个月(水平类特征=锚点月末值; 变化类=窗内计算)。特征窗下限: 候选锚点自身须有完整特征窗。
- **检索范围**: 锚点前全部有效候选锚点月, **排除与锚点特征窗重叠者**(候选锚点月 M ≤ M0−12), 理由: 重叠窗共享观测, 自相关会造成"相邻即相似"的伪 TOP-N; 排除规则写死并披露 dropped_overlap 计数。
- 事后演变窗(§1.5)与检索严格分离: 检索库只含 t≤候选锚点月末的数据; 任何 t>候选锚点的数据只出现在 aftermath 块, 永不进入相似度。

### 1.4 泄漏防护硬规则(实现清单, 逐条可测)

1. z-score 基准 μ/σ 只用 t≤(各自)锚点月末观测(expanding); 禁止全样本统计。
2. 候选检索特征只用 t≤候选锚点月末数据; 锚点特征只用 t≤锚点月末数据。
3. 重叠窗候选排除(M ≤ M0−12)。
4. aftermath(事后表现)单独计算、单独标注"事后", 且**不参与排序**; 候选事后窗超出当前数据末端 → 该 horizon 标 available:false, 禁止缩短窗冒充。
5. 月度宏观=最新修订值(非当时初值) → 工具输出整体挂 `research_mode_gate` 继承块: descriptive=available / event_study=按各特征指标 release_date_available 交集 / realtime_info_set=按 _vN 存在性(现状恒 blocked), 并强制携带"当时市场所见状态可能与修订后档案值不同"文案。
6. 估值维度缺席期, 不得用价格水平倒数(如 1/PE 未知时不得拿价格涨幅冒充估值)等任何推导值填补; 缺席=缺席。

### 1.6 样本量与拒答阈值

- 有效候选 N2 ≥ 24: 正常输出。
- 8 ≤ N2 < 24: 输出但每条 warning"候选仅 N2 个(<24), 相似排名与分位不稳, 结论弱"。
- N2 < 8: **拒答**(kind=insufficient_candidates), 提示扩展采集窗; 不输出 TOP-N(个位数候选的"最相似"没有统计意义, 宁缺毋滥)。
- 锚点任一已启用维度 coverage<0.5: warning; <2 个维度有数据: 拒答。
- **现状预判(验收用)**: 当前 22 个月历史下, 有效候选(需 36 个月 z 历史)≈0 → 工具在现数据上必然走 insufficient_history/insufficient_candidates 拒答——**这是正确行为**, 验收案例 B 因此必须在采集扩展落地后执行(见 §4)。

### 1.7 巧合 vs 机制: 引擎机械判据(可确定性计算)与标注义务

引擎侧(写入 warnings/disclosure, 机械触发):
1. **单维主导**: 某 TOP 候选单一维度 contribution_share > 0.6 → flag"相似性由单一维度主导, 跨维度结构印证弱, 巧合可能性高"。
2. **事后分歧**: TOP-N 某资产某 horizon 的方向一致率 < 0.6(如 5 个相似期中 3 涨 2 跌) → flag"相似期事后走向分歧, 提示结局依赖相似期之外的条件, 不支持确定性路径推演"。
3. **维度缺席**: 有效维度 <6(现状: 估值恒缺席) → 恒挂"未覆盖维度可能是共同驱动(缺变量), 相似性解释力受限"。
4. **距离不分离**: TOP-1 与中位候选距离差 < 10% → flag"TOP-1 未与候选分布分离, '最相似'表述降级为'处于相似簇'"。

Agent/Skill 侧(非引擎能力, 界限所在): 定性事件对照(候选期"当时发生了什么"——政策转折/危机事件)引擎**不知道也不猜**, 由 Agent 以【假设】层给出并标注"事件知识非引擎数据"; 引擎只为该环节提供数据侧证据(当时的利率/信用/波动轨迹, 经 history --start/--end 取数)。

### 1.8 CLI 面(最小)

`python3 ia_cli.py analog [--anchor YYYY-MM] [--top N] [--weights g,i,r,c,v,val] [--no-aftermath]`
默认: anchor=最新完整月, top=5, weights=等权, aftermath=开。只读, 零网络, 复用 rhq 载入/月网格/单位感知件。不进 research 问答栈(独立能力, 与 compare 并列)。

## 2. 传导机制证据标准

机制链例: 政策利率 → 实际利率 → 美元/资本流动 → 金融条件 → 盈利与估值。
每一环必须落级并随行证据引用, 三级定义:

- **E1(引擎直接可验证)**: 该环两端都有引擎序列且关系可由确定性计算刻画——同步相关(compare, 含 change_basis/月网格/警告全随行)、领先滞后(--lag, 仅可表述"A/B 谁先动 k 期", 禁写"驱动")、滚动稳定性(--window, 机制强度的时间一致性)、水平区间变动(interval_change)。证据引用=具体命令输出字段原值。
- **E2(引擎部分支持)**: 链两端可验证但中间环节无序列(如"资本流动"无数据) → 可验证环给 E1 证据, 缺失环明写"本引擎无 X 序列, 此环为【假设】"。
- **E3(纯叙事)**: 两端均无数据(如"盈利预期变化") → 整环【假设】+ 必须给证伪指标(§3)。

披露格式(固定模板, Skill 强制):
```
环节 k: [E1|E2|E3] 「A→B」
  证据: <E1 时: 命令+字段原值; E2/E3 时: 无/部分>
  陈述边界: 相关≠因果; --lag 只证时序先后不证因果; 样本窗 <观测窗>
```
禁止写法(负例, 进 Skill): "紧缩政策导致黄金下跌" → 必须改写为"FED_FUNDS 领先 GOLD_F k 期变化相关 ρ=…(E1, 时序先后)+ 传导经由实际利率(TIPS_10Y×GOLD_F ρ=…, E1)+ '政策→汇率/流动'环为【假设】(E2)"。

## 3. 条件推演标准(情景表模板)

情景: <政策/宏观路径假设, 明写"假设非预测">

## 4. 三个验收案例执行设计

通用链路: 数据证据 → 推导 → 历史对照 → 传导 → 条件推演 → 证伪指标; 每步标注引擎命令与四层标记。

### 案例 A: 当前全球宏观环境关键矛盾+驱动因素+跨资产影响
1. **事实基线**: `overview --economy US,EA,JP,CN` + `changes`(原始值+观测日+缺失如实)。
2. **矛盾识别(数据侧)**: `compare --metrics` 四组结构相关: CORE_PCE×FED_FUNDS 不足(月×月, 现数据 n≈20 警示)/TIPS_10Y×UST_10Y(通胀分解: 名义−实际)/CURVE_2S10S×HY_OAS(增长预期×信用)/SPX×HY_OAS(风险偏好一致性)。矛盾陈述=哪些相关处于窗口内异常(引用 rolling 端值)。
3. **驱动因素**: 每个候选驱动给 E1/E2/E3 分级(§2 模板); 无序列的驱动(如财政)直接【假设】。
4. **跨资产影响**: 变化相关矩阵 `compare --assets`(12 对, 披露随行)+ 关键对 --window 60 稳定性。
5. **如实声明**: 无 GDP/估值/EA·JP 政策序列 → 矛盾图谱在增长与估值维度标注"数据缺席"; 现状约 1 年窗口, "结构性"结论必须限定窗口。
6. **产出纪律**: 全部判断四层标注; 每个矛盾附证伪指标。

### 案例 B: 与当前结构相似的历史时期(需采集扩展后执行)
1. `history`(catalog)确认特征覆盖 → `analog --top 5`(现状数据下预期**拒答 insufficient_*, 属正确行为, 验收先跑这一步记录拒答路径)。
2. 扩展后: analog 输出 TOP-5 + 各维贡献 + 事后表现(带"事后非预测"标签)。
3. **当时发生了什么**: Agent 给事件叙述(【假设】层, "事件知识非引擎数据"), 数据侧用 `history --metric UST_10Y --start <候选窗> --end <候选窗+12m>` 等取候选期轨迹佐证/对照。
4. **关键差异**: 逐维 z_gap 反读(引擎给 dims 贡献, Agent 解释含义, 差异>1σ 的维度必须点名)。

## 5. Skill 修订要点(三禁令不动, 新增边界)

现有三禁令(编造数据/确定性收益承诺/自动交易)保留原文。新增建议:
1. **允许项表述**: "允许且有义务进行有证据的机制分析与条件推演——但每个机制环节必须标注证据级(E1 引擎输出原值/E2 部分/E3 假设), 每个情景必须五行齐备(假设/判断/敏感变量/证伪指标/触发条件); 无证据的机制叙述只能落在【假设】层且必须给证伪指标。"
2. **analog 使用纪律**: 相似检索结果必须随行固定披露文案(相似≠因果≠预测/事后块标签/巧合 flag); TOP-N 不得浓缩为"历史上最像的时期是 X, 当时 Y 上涨, 所以现在 Y 会涨"——此句式为违规(以事后冒充预测)。
3. **推演与预测的分界**: Skill 收录 §3 固定文案+负例; 点位/时间/概率(除非引擎输出)一律禁止。
4. **四层标注衔接**: 机制环节的 E2/E3 归【假设】, E1 引用归【事实】(引擎字段原值), 对 E1 的解读归【推断】——与现有纪律 4 无冲突, 补一句映射说明即可。
