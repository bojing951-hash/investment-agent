# audit/ 验收与复验报告目录

本目录收录各 Charter 轮次的独立复现、修复复验与最终验收报告
(P0 复现 / 修复复验 / 数据批复验 / 终验),作为"开发者不自验、独立席位
交叉验证"纪律的留档。自 Charter 9 起随仓库入库(此前各轮仅存本地)。

## 公开版消毒说明

入库版对报告正文做过两类机械替换,语义保持不变:

- 特定模型厂商字样(含其历史环境变量名)→ 中性占位(`厂商A`/`厂商B`),
  遵循本仓库公开面厂商字样纪律;
- 本机绝对路径(`/Users/...`)→ `~`。

未消毒原版存于维护者本地归档,不入公开仓。消毒仅涉及上述两类字样,
判定、数值、命令、路径结构均未改动。
