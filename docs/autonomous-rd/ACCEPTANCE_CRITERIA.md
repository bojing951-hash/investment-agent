## 现行验收纪律(2026-11 各章程验收实践确立)

1. **六层区分**: 代码实现 / 合成测试 / 真实数据 / 真实机构资料验证 / 完整 Agent 流程 /
   Web 实际使用——未实际执行不得标 PASS。
2. **CI 绿 ≠ 最终目标达成**;不得未经真实验收宣布最终完成。
3. **独立审计**: 开发者不自验;独立席三态裁决 PASS / FAIL / NOT_VERIFIED;数值类结论独立复算。
4. **反例测试**: 正确拒绝/降级/标不足 = 合格(未到期禁判定、缺出处、样本不足、无历史档案等)。
5. **冻结合同不可改**: 验收合同冻结后不得为 PASS 修改一字。
6. **真实性红线**: 缺失不填零、合成不冒充真实、来源可定位、统计口径明确
   (利率 pp/bp、价格 %、窗口按真实日期截取、价格收益 vs 总回报、交易日历、无前视)。
