## 最终标准(总指令 §八,原文登记)

> 原文全文见 `PRODUCT_GOAL.md` §八;执行与复核结果登记于 `FINAL_ACCEPTANCE.md`。

- **AC1 真实全球宏观全景** — 真实数据生成主要经济体与市场当前状态;展示指标、变化、数据日期、来源和缺口。
- **AC2 真实机构研究** — 从合法公开原始资料获取机构观点;每条可追溯机构/报告/发布时间/原始内容;区分机构明示与 AI 推导。
- **AC3 正确的机构观点验证** — 区分提出时证据/发布后新信息/到期后结果;方向、期限、新鲜度、历史修订必须正确。
- **AC4 经济机制与历史研究** — 检索历史相似结构、解释后果、研究传导;区分统计事实/因果假设/条件预测。
- **AC5 独立研究结论** — 以客观证据评价机构观点,识别分歧、关键未知、预期差;结论须有竞争性解释与证伪条件。
- **AC6 真正的一键研究** — 一条自然语言指令在兼容 Agent 环境自动完成完整研究,真正执行工具调用;Web 一键只做确定性数据+已有成果,不得冒充完整 AI 研究。
- **AC7 真实端到端验收** — 三项真实研究任务(全景/机构观点与分歧/交叉验证)+ 至少一项未专门优化过的开放式研究问题。
- **AC8 研究可复核** — 数据/观点/统计/结论可追溯;独立审计者能复算关键数值并判断结论是否超出证据。
- **AC9 真实用户可用** — 干净环境实际执行: 安装→数据配置→更新→一键研究→地图→追溯→归档。
- **AC10 可靠性与安全** — 不编造数据/观点、不绕付费墙、不未授权付费、不泄密钥、不自动交易、不破坏档案、合成不冒充、CI≠验收。

## 现行验收纪律(2026-11 各章程验收实践确立)

1. **六层区分**: 代码实现 / 合成测试 / 真实数据 / 真实机构资料验证 / 完整 Agent 流程 /
   Web 实际使用——未实际执行不得标 PASS。
2. **CI 绿 ≠ 最终目标达成**;不得未经真实验收宣布最终完成。
3. **独立审计**: 开发者不自验;独立席三态裁决 PASS / FAIL / NOT_VERIFIED;数值类结论独立复算。
4. **反例测试**: 正确拒绝/降级/标不足 = 合格(未到期禁判定、缺出处、样本不足、无历史档案等)。
5. **冻结合同不可改**: 验收合同冻结后不得为 PASS 修改一字。
6. **真实性红线**: 缺失不填零、合成不冒充真实、来源可定位、统计口径明确
   (利率 pp/bp、价格 %、窗口按真实日期截取、价格收益 vs 总回报、交易日历、无前视)。
7. **用户三保留卡点**: 合并 main / 付费凭证 / LIVE 部署,须用户亲自批准。
