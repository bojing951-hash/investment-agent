## 一、P1-① 统一时间要求的完整性校验(scripts/research_orchestrator.py)

### 根因

时间词形的**数量转换与约束提取逻辑分散在多条正则与多个入口**(`_RANGE_MONTHS_RE`/`_RANGE_YEARS_RE` 六七条分支、`_iter_range_*` 两套迭代器、窗口解析/约束收集/年限月数 helper 各自消费),任何一条分支对某类词形(无「个」的「十八月」、全角数字、残缺点串、零值、「半」后缀、小数折月)不匹配,该约束就静默落回"未限定"→max_available 交付;明确研究年份则从未被纳入要求。**修复不是为审计句子加特例,而是把词形扫描收敛为单一扫描器+三态契约**(确实未指定→max_available / 已完整解析→准确窗口 / 已指定但无法完整解析→明确拒绝并阻断正式报告与归档)。
