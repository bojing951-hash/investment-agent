# 常驻独立语义审计席(Operative Charter)

**设立**: 2026-11-15,用户授权「开」(ARCH-REFORM-FINAL-REPORT 非阻断遗留项之三)。
**契约依据**: ARCH_REFORM_PHASE2_CONTRACT.md §4b(I/O 契约)+章程 6.2。
**席次**: R32(T-R32-1)。

## 1. 席位性质

- **真独立 Subagent**: 每次裁决由无 dev 树上下文的全新子代理执行;简报只含
  职责+待审工件路径+输出 schema,**不含开发者期望**。席可拒开发者声明
  (UPHELD 不欠,REJECT 不留情)。
- **审什么**: 确定性验证(文本一致性/阈值/断言复算)覆盖不了的残余面——
  narrative 措辞与证据的**语义**相称性、推断链是否越界、竞争解释与反例。
- **不审什么**: 数值对错(那是 deterministic 层的事,数值矛盾应已被拦)。

## 2. 唤起点(§4b)

(i) text_consistency 产出 SEMANTIC_REVIEW_REQUIRED 非空;
(ii) qualitative_inference / forecast 型 claim 待裁;
(iii) 超时策略触发前; (iv) 任何席位/用户提请。

## 3. 读取面

claims bundle(judgment 档 l3/l4)全量 + narrative 全文 + 被引证据原文
(运行档 L1 rows: value/unit/observation_date)+verifier 结果(含修订史)。

## 4. 职责(六查+证伪,须主动找反例)

证据相关性 / 支持度(定性措辞 vs 证据强度)/ 竞争解释 / 反对证据 /
结论是否超出证据 / 证伪条件可观测性。
每项裁决至少一次「反方攻击」尝试并记录攻击与结果。

**地图问句加查三项(Audit-R28 任务3,历史段同步面在场的裁决必查)**:
- **机制链复核**: reader_map 传导叙述的每一环标注的证据级(E1/E2/E3)
  与该环实际证据相称性——E2/E3 环节不得以事实位措辞出现;环内数字
  须可回贴引擎面(对质表 face_off_verdict 与区分指标一致)。
- **竞争解释复核**: 主解释的竞争解释在列且**真正竞争**(同证据容纳),
  不是稻草人;「尚不能区分」结论须与对质面数据一致——区分指标确已
  给出分离则不得以含糊收场。
- **区分指标复核**: 被点名的区分指标须真能区分(两解释在其上的预言
  方向确实相反/不同幅),且该指标在证据面在场——缺席的区分指标=证伪
  条件不可观测,按六查末项处理。
- **历史段同步性复核**(同步面在场时): 判断叙述的同步/分化主张须与
  引擎地区×维度同步面标签一致;叙述与面冲突、或叙述声称同步而面=缺证,
  均为 REVISE 必修。

## 5. 裁决词表与状态迁移

| 裁决 | 含义 | 迁移 |
|---|---|---|
| UPHELD | 维持 | 写入 claim.verification,可发布 |
| REVISE | 需修订 | claim 级修订(原句→改句)+重渲,同 R24 修订闭环但常驻化 |
| NOT_VERIFIED | 证据不足 | 禁入【事实】区;可入观点区带标注 |
| REJECT_ENTRY | 剔除 | 从正文剔除+披露剔除后发布 |

## 6. 归档协议(append-only)

- 路径: `audit/semantic_review/YYYYMMDD/VERDICT-<target>.json`(席位产出
  原文逐字落档,开发者不得改写)+ `MANIFEST.md`(唤起点/席次/对象/结论一行)。
- 改判=新档新日期,**不覆写旧档**;修订闭环的产物(REVISE 的 from→to)随档。
- 逐次落档,裁决+依据+引用面内真实数值(禁凭记忆编数)。
