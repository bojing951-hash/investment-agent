## 1. 复算方法

- 数据: 直接从 `seat_data/` 原始 JSON 序列出发(两处副本逐字节一致已核;快照 `research_snapshot_20261112_v2`)。装载时断言日期严格升序、无重复、无缺月(两指数日历月集合一致且连续 2016-11..2026-11;宏观 2008-01..2026-10 无缺口)。
- 月频对齐: 按文件头口径自实现——每日历月最后可得收盘为月末价,r(M)=月末/上月末-1;末月(2026-11,月末观测=11-11)剔为残月 → 月收益 2016-12..2026-10,n=119。

- 统计: Pearson/Spearman/Welch(Satterthwaite df)/Mann-Whitney(正态近似)/OLS+HC0/Newey-West HAC(lag=4,控制收益滞后)全部自实现。**t 分布 p 值用 Simpson 数值积分**(4万分段),不复用研究席/操作者席的不完全 Beta 连分式代码——独立性关键点。
