# BLIND 可独立重放证据包(Audit-R4 R4-03 同版重放)

目标: 任何人在干净目录, 不依赖本机 `~` 或 `/tmp` 路径, 一条命令完成两件事——
(a) 以本包**原始输入切片**重放研究席自算脚本并与其冻结输出逐字节比对;
(b) 以**独立实现**从同一切片复算 FULL_REPORT 正文引用的全部关键统计值与
样本数量(64 项靶值), 逐项比对。

## 一条命令重放

```sh
sh docs/autonomous-rd/phase4/BLIND/blind_replay.sh
# 期望末行: BLIND REPLAY PASS: 冻结输出拼接 sha256=feaa1536dc19404fd316cebada87caa8076884b106dd5b6426c379b93dee1c23 (切片重放逐字节一致 + 独立复算全中)
```

脚本行为: 临时空目录 → 拷入 `blind_calc.py` + `blind_calc2.py` +
`blind_independent_recompute.py` + `data_slice/` → 先核验切片 sha256 →
`IA_ENGINE_DAILY=<临时目录>/data_slice/data/daily` 重跑两脚本并与
`blind_calc_output.txt`/`blind_calc2_output.txt` 逐字节比对 → 跑独立复算
(自带退出码)。已在本机验证 PASS, 且从仓库任意 cwd 运行均可(脚本内以
自身位置定位包件)。

## 包内清单

| 件 | 说明 |
| --- | --- |
| `blind_calc.py` / `blind_calc2.py` | 研究席自算脚本(数据根可由 `IA_ENGINE_DAILY` 覆盖; 含 Audit-R1 F05/F06 与 Audit-R2 条目3 修) |
| `data_slice/` | **原始输入切片**(非计算输出): GOLD_F/DXY/VIX 逐值拷贝自 research_snapshot_20261112_v2.json; UST_10Y/BEI_10Y/TIPS_10Y/HY_OAS 逐值拷贝自 macro_20261112.json; schema 形状与源文件同, 附 `slice_note` 注明排除面 |
| `blind_calc_output.txt` / `blind_calc2_output.txt` | 冻结输出(重放逐字节比对锚; 与引擎树原跑逐字节一致——切片等价性已在制包时以 engine-vs-slice 双跑 diff 验证) |
| `blind_independent_recompute.py` | 独立复算席: 全新实现(不 import/不复用 blind_calc 代码路径), 只读切片, 64 项正文靶值(滚动时点值/负值带极值/年度相关与 t/敏感度 beta/两套分状态 n 与相关/水平二象性/极端日桶/2018-19 先例窗/2026 路径锚/证据锚与派生自洽) |
| `blind_replay.sh` + 本文件 | 重放入口与口径台账 |

## 独立复算结论(2026-11-17, Audit-R4 R4-03)

64 项靶值 64 中 0 失配。正文全部关键统计值与样本数量在独立实现下复算一致;
唯一跨路径分歧为带边括注第 4 位小数(浮点求和路径噪声, 已在上表披露, 不触及
任何结论性声明)。**未发现需要修正正文数值的情形, 故未触发 R4-02 正文改动
→裁决失效→重审查链。**

判定纪律注记: 独立复算席首轮自检曾 10 项失配, 逐项溯源后 8 项系复算席自身
靶值构造错误(把正文局部时点值当全局极值/把月末收盘锚当区间最低/硬编码估计
值)与一处逐日差分环绕 bug(恰为 Audit-R2 NEW-2 在研究席修过的同类缺陷,
独立席重蹈后自查修正)——全部为复算席侧修正, 原始输入与正文数值零改动;
此过程留此注记以自证"不得调整样本迎合旧数字"的执行方向。
