### 证据最充分: 美国通胀再加速→负实际利率→政策反转(市场长端定价为竞争解释面)
① **CPI 同比 2026-02=2.434% → 2026-05=4.167%(+1.73pp,过去一年全库最大三维滚动变化);CORE_CPI 后段跟进(2026-07=2.4665% → 2026-10=2.8697%);BEI_10Y 同期仅 +13bp(2.25→2.38,最新 2.20)**
   - 因果假设: 通胀加速压低实际政策利率(名义 DFF 3.88 − CPI 4.08 ≈ −0.2pp),负实际利率反过来强化通胀持续性,倒逼政策由降转升(2026-09-17 起)—— mandates 渠道
   - 竞争解释: 供给侧/能源冲击推升标题通胀而需求面并未过热(失业率 4.1 持平、GDP 同比 ~2.1% 持平、工业同比 2.15% 温和)——政策反转是防御性保险而非需求过热应对
   - 能区分解释的指标: CORE_CPI
→ **同观测日 2026-11-16 复算 UST_10Y 5.12% = TIPS_10Y 2.92% + BEI_10Y 2.20%(恒等式残差 0.000pp);市场通胀补偿 2.20% 远低于现货 CPI 4.08%(BEI 单独末观测 2026-11-17=2.21;三利率同日公共日取 11-16)**
