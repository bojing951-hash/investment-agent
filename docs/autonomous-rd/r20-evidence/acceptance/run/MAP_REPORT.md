## 证据最充分的传导机制(有文字的传导图)

### 中国生产端再通胀 → 美欧消费通胀再加速 → 央行再紧缩 → 实际利率上行 → 资产重定价
① **CN_PPI_YOY 同比 2026-02 为 -0.9、2026-03 转正至 0.5、2026-05 达 3.9、2026-10 达 5.7;美欧消费通胀同月(2026-03)转身: 美国 CPI 同比(引擎转折口径)2026-02 为 2.434→2026-05 为 4.1666;EA_HICP_YOY 2026-02 为 1.9→2026-05 为 3.2(引擎月度序列)。**
   - 因果假设: 假设中国生产端价格上行经出口商品价格与全球供应链传导,推升美欧商品价格,是美欧 CPI 再加速的贡献项之一。
   - 竞争解释: 若再加速主要由各国内需与服务业工资驱动,或由能源大宗商品驱动,则与中国生产端价格无关,同步只是巧合。
   - 能区分解释的指标: CN_PPI_YOY
→ **市场定价面: 引擎共同交易日窗 2026-10-16→2026-11-17,美国十年期盈亏平衡通胀 BEI_10Y 变动 -14bp(共同交易日窗内 2.35@2026-10-16→2.21@2026-11-17;窗后最新观测日 2026-11-18 为 2.19),实际利率 TIPS_10Y +15bp——市场并未为通胀传导定价,反而为实际利率定价。**
