## 一句总判断

过去一年全球主线:通胀实现值普遍回升(中国 PPI 由负转正并加速、美欧消费通胀走高、日本下半年再升温),美欧央行转向加息(欧央行先行、美联储由降转加),而美债名义利率的上行几乎全由实际利率贡献、盈亏平衡通胀预期基本走平;若该结构延续,基准情景(SCN-A)=金融条件收紧、风险资产与贵金属承压、美元偏强,反例情景(SCN-B)=增长放缓主导、政策转松、风险资产修复;基准情景的失效方向=盈亏平衡通胀趋势上行切向通胀预期失控叙事,两情景的证伪指标分别为 BEI_10Y 与 EA_HICP_YOY(阈值见情景节);日本全年持续加息但节奏独立,中国政策利率按兵不动并以新隔夜锚运行为标志。条件式判断,假设非预测。
