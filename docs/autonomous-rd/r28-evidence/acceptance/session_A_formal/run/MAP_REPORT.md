## 一句总判断

过去一年全球宏观的主线不是衰退而是通胀中枢上移后的政策再定价: 美欧中通胀同比 2026 年春季同窗走高、增长大体平稳;ECB 最先转入连续加息、Fed 先降后升(一年净变动为零)、日本渐进收紧、中国按兵不动并换锚,四地政策分化;美债十年期名义利率年度窗 +91bp = 实际 +102bp + 盈亏平衡 -11bp,实际利率承载了几乎全部上行;近一月风险资产与黄金深回撤(SPX -10.92%、GOLD_F -15.29%)、VIX 翻倍、HY_OAS 自 8 月末明显走阔——实际利率上行与增长担忧两通道证据并存,单月窗口尚不能区分主因;后续走向取决于通胀回落速度与政策反应的赛跑(条件判断,非预测)。
