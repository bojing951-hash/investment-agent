## 一句总判断

过去12个月全球宏观地图的主线是『再通胀脉冲+政策再紧缩+高估值重定价』: 美国从『增长稳健+通胀中性+降息』走向『增长放缓+通胀回升+重启加息』(CPI 同比 3.02→3.72 最近有效,实际利率12个月上行102bp 主导名义利率),中国是唯一『价格再通胀但政策按兵不动』的背离方(PPI 同比 −2.1→+5.7 而 OMO/LPR 三期不动),欧元区两度加息,日本持续正常化(政策利率 0.477→1.227);11 月风险资产急跌(SPX 月窗 −10.92%、VIX 月窗 +115.17%)与『政策再紧缩×高估值』组合相容,与流动性冲击叙事在月频分辨率下尚未区分。
