### 通胀再上行→紧缩定价与流动性压力→风险资产承压+美元走强(证据最充分)

   - 竞争解释: 美欧同窗上移是基数与口径因素的巧合叠加,非共同传导——后续各地将独立波动。
   - 能区分解释的指标: EA_HICP_YOY (引擎当前面: 2026-10-01=4;近30日窗口内无新观测——最近两期 2026-09-01=3.8→2026-10-01=4,Δ+20bp)

   - 竞争解释: 长端利率月窗回落由增长担忧与避险驱动,与通胀预期无关;高位利率是前期水平的延续而非新增紧缩定价。
