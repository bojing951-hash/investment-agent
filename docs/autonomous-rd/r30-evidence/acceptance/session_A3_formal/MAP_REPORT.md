① **2026-02→2026-05 同窗通胀上移: 美国 CPI 同比(引擎派生口径)2.434→4.1666、中国 CN_PPI_YOY -0.9→3.9、欧元区 EA_HICP_YOY 1.9→3.2(引擎转折候选面,月频);美国 CORE_PCE 同比 2.85(2025-08 观测)→3.12(2026-09 观测)。**
   - 因果假设: 全球价格压力(供给与需求混合)经贸易品、大宗与预期渠道跨区传导,通胀中枢同步上移。
   - 竞争解释: 三地通胀同窗上移是本地独立因素(中国行业供给侧整合、欧元区能源与基数、美国服务黏性)的巧合叠加,非全球传导。
   - 能区分解释的指标: CPI (引擎当前面: 2026-10-01=337.476;近30日窗口内无新观测——最近两期 2026-09-01=336.298→2026-10-01=337.476,Δ+1.178 指数点(+0.35%))
→ **政策再定价跟进: ECB 2026-06-11、2026-09-10 各 +25bp(ECB_DFR 2.0→2.5);Fed 2026-09-16 +25bp(DFEDTARU 3.75→4.0,决议构成跨国同一事件簇 POLCLUSTER-03);日本 JP_POLICY_RATE 月均 0.477→1.227 渐进抬升;中国 CN_OMO_7D 1.4 与 CN_LPR_1Y 3.0 按兵不动。**
   - 因果假设: 央行对通胀上移作出反应,政策利率进入再紧缩轨道(决议→生效分记: Fed 次日生效、ECB 决议后首个周三生效)。
   - 竞争解释: 政策变动主要反映增长韧性与汇率/金融稳定考量,而非通胀驱动。
   - 能区分解释的指标: BEI_10Y (引擎当前面: 2026-11-20=2.15,近30日2.32→2.15,下降17bp)
→ **长端利率升至高位而曲线走平: UST_10Y 4.02→5.04、UST_2Y 3.47→4.76(2025-11-28→2026-11-19 月末口径),CURVE_2S10S 0.55→0.29,BEI_10Y 2.23→2.15;TIPS_10Y 序列不可得,实际利率分量无法直接验证。**
   - 因果假设: 政策重定价推升短端与全曲线,通胀预期温和使名义上行主要由非通胀分量承载。
   - 竞争解释: 长端上行主要由财政供给与期限溢价推升,与政策预期无关。

   - 因果假设: 高利率与波动冲击压低长久期风险资产与非孳息黄金的估值,并支撑美元。
   - 竞争解释: 回撤由增长担忧与盈利预期下修驱动,与利率无关。
