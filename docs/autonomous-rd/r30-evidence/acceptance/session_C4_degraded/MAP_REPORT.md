## 一句总判断

过去一年四大经济体从「增长放缓+通胀回落+宽松收尾」转入「增长分化+通胀再抬头+政策重新收紧」:中国生产者价格结束通缩(PPI同比自2026-02的-0.9升至2026-05的3.9,最新一期5.7),美国headline通胀同窗抬头(CPI同比自2.434升至4.1666,最近有效同比3.72)并伴随美联储2026-09逆转加息(目标区间上限自3.75回到4.00),日本政策利率持续正常化(月均自0.477升至1.227)且方向全年未变,中国政策利率按兵不动——最新一期市场呈股、金、非美股指同跌+波动率跳升+美元走强的风险收缩相,四地中政策方向一致收紧的只有美日,中国背离,欧元区本地数据不可判。
