① **通胀分化端: 欧元区 HICP 3.0→4.0(观测月 2026-04→2026-10,非单调: 夏季回落至 2026-06 的 2.8、秋季 3.8/4.0 再冲高),日本全国 CPI 1.38→2.44(六个月连升、9 月起站上 2,东京都先行口径 2026-09 已 2.69);终点水平差 1.56个百分点,六个月累积升幅相近(+1.0 对 +1.06个百分点)。**
   - 因果假设: 同一全球价格压力(能源与供给约束+服务黏性)在两地以不同强度传导: 欧元区弹性高、日本从低位启动,形成水平差维持而斜率相近的格局。
   - 竞争解释: 两地通胀各自独立运行(欧元区能源与基数摆动、日本工资-价格传导初段),表观分化是独立周期的叠加;另有口径解释——事后回顾修订值与统计口径(权重/覆盖)贡献了部分水平差。
   - 能区分解释的指标: EA_HICP_YOY (引擎当前面: 2026-10-01=4;近30日窗口内无新观测——最近两期 2026-09-01=3.8→2026-10-01=4,Δ+20bp)
