## 5. 六查逐项结论

六查 = 证据相关性 / 支持度 / 竞争解释（真正竞争、非稻草人）/ 反对证据 / 结论是否超出证据 / 证伪条件可观测性。对四条 L3 矛盾陈述、两条机制链逐条执行；另核历史类比零段的理由。下列数字全部取自冻结快照 series_store、冻结日历或 report.json 引擎面，逐点出处见附录 A 对应类别。

### 5.1 C1-POLICY-DIVERGENCE（美日同向收紧、中国可比口径未变）
