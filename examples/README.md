# 公开研究样例

本目录存放**真实生成并经过质量门禁校验**的研究报告样例,供你在安装前判断
本系统能实际产出什么。样例**数值层**与生成时刻原始产出一致;**解释层**已按
下方勘误节修订(不假装逐字节一致);原始未修版可从 git 历史取(2ec8714)。

| 文件 | 类型 | 研究窗口 | 生成模型 |

## 数据来源

样例数值来自以下免费数据源经 13 步采集流水线汇集(当日快照含 94 项指标事实):

- 美股/全球资产行情: Yahoo Finance(yfinance)
- 美国宏观序列: FRED(圣路易斯联储); 联邦基金期货隐含利率: CME Group
- A股/港股/中国宏观: akshare / tushare
- 日本国债收益率与政策利率: 日本银行(BOJ)公开数据 / 日本财务省
- 欧元区利率与通胀: 欧洲央行(ECB)公开统计
- 新闻摘要: Finnhub(RSS/新闻API,可选)

每项指标事实在系统内部均带观测日期、来源文件与内容指纹(sha256)留痕。

## 数据质量说明(如实披露)

该期报告双门禁状态为 **DEGRADED(降级通过)**——不是 FAIL,也非全绿:

- **Gate A(数据质量) DEGRADED**: 非核心指标缺失 7 项(德国/法国国债与股指、
  中国OMO与资金通道、东京CPI——采集通道待建),14 项事实因数据源发布滞后降级;
- **Gate B(数值校验) DEGRADED**: 6 项警告(报告中已逐项披露,如 ICSA 初请
  失业金两口径并存)。

降级意味着: 报告正常生成,但涉及降级指标的结论可靠性受限,报告末尾附自动
追加的降级披露块。这是系统的诚实性设计——**宁可披露降级,不假装数据完整**。

## 事后勘误(2026-11-08,Skill 化轮)

原始发布版在解释层含一处真实错误,已在本样例中修正并留档作为反例教材:
资产表 EEM 行曾写"受日本拖累(代理含日本权重)"——数据包不含任何指数成分/
权重数据,该归因属模型编造(且 MSCI 新兴市场指数按口径不含日本),数值本身
无误、锚点核验通过,故未被只核数值的 Gate B 拦截。修正后: EEM 行改口径标注,
比较3 归因句降级为【假设】并明示不可验证,5.3 补 EWJ(美元代理)与日经225
(本土指数)双口径披露,资产表恢复 ETF 代理脚注。此案例推动了 Agent Skill
研究纪律(禁成分编造/事实位因果禁令)的落地,详见
`.agents/skills/global-macro-research/references/research-discipline.md`。

## 事后勘误(2026-11-09,批2样例勘误轮)

- **Brent-WTI 价差基数修正**: 报告第三节/第五节两处「从约19美元收窄至
  7.49 美元」→「从 13.52 美元收窄至 7.49 美元」。依据: 周基准价差 13.52
  (数据包当日口径);90 日窗口最大 14.05、1 年最大 16.97——原「约19」在
  任何窗口口径下均无数据依据,属模型生成错误(方向性结论不受影响)。
- **债券 ETF 口径脚注补充**: 第二节资产表脚注补「债券类 TLT/IEF/SHY/HYG
  为价格型 ETF,涨跌与收益率反向,不可当利率读数」,防跨口径误读。
  依据: 债券价格与收益率反向的标准口径;原文缺此句。

以上两处均为解释层修订;数值层未动,原始未修版见 git 历史(2ec8714)。

## 使用限制

1. 本样例为**研究材料**: 整理与解释公开宏观数据,不含投资建议、资产配置、
   评级或价格预测(产品红线,见根目录 PRODUCT-GOAL.md)。
2. 数据可能有误或滞后: 免费数据源存在修订与延迟,数值请以原始来源为准。
3. 报告中的【推断】【假设】标注内容为模型解释性分析,非事实陈述。
4. 转载请注明数据窗口与生成本项目(investment-agent)。

(周报样例为**当时的智谱 GLM 生成之历史产物**,原样保留;2026-11-09 起
模型面中立化——可选任意 OpenAI 兼容端点,未配置则产出 data-only 确定性
数据观察周报,见 USER_GUIDE 第 2 节。)
